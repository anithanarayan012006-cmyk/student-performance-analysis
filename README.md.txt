# Student Performance Analysis Using SQL

## 📌 Project Overview

This project analyzes student academic performance using SQL.

The analysis focuses on student marks, subject-wise performance, attendance, and identification of high-performing and low-performing students.

## 🛠️ Tools Used

- SQL
- SQLite
- Online SQL Editor
- GitHub

## 🎯 Objectives

- Calculate average student marks
- Identify the highest and lowest performers
- Compare subject-wise performance
- Analyze student attendance
- Identify students scoring above 80
- Find the top-performing students
- Generate useful insights from student data

## 📊 Dataset

The dataset contains information about 10 BCA students.

Columns include:

- Student ID
- Student Name
- Gender
- Age
- Course
- Subject
- Marks
- Attendance

## 🔍 Key Analysis

The project uses SQL operations such as:

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- AVG()
- COUNT()
- LIMIT

## 📈 Key Findings

- Average marks: **79.7**
- Average attendance: **86.3%**
- Highest scorer: **Divya – 95 marks**
- Lowest scorer: **Arjun – 65 marks**
- Best-performing subject: **Java – 82.5 average marks**
- Lowest subject average: **SQL – 74.66**
- Lowest attendance: **Vivek – 73%**
- Students scoring above 80: **5**
- Percentage scoring above 80: **50%**

## 💡 Insights

Java had the highest average marks among the three subjects.

Half of the students scored above 80 marks, indicating that 50% of the students were high performers based on the selected threshold.

The analysis also identified students with lower attendance who may require additional academic attention.
